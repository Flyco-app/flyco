## Simplification

Retain one Next.js deployment and no extra backend/ORM. No speculative modules or packages. Keep the complete domain model as a design reference but migrate only the slice required by a phase. Remove redundant indexes rather than adding blanket indexes. Preserve separate financial and fulfillment states: collapsing them would lose delivery history during refunds and disputes. Defer full ledger enforcement, allocation logic and queues until the money/notification phases; their reference tables are not a finished accounting system.

## Remaining gates

Phase 1 remains blocked by the roadmap's Phase 0B delivery controls and unverified full local Auth/email stack. Main protection and production reviewers were previously rejected by the current private-repository plan. Vercel preview ownership/commit/content and staging release have not been proven; Sentry access is not connected. This review neither changed billing nor bypassed those gates. The foundation checks can pass while these operational prerequisites remain unresolved.

Before payments: confirm platform entity, supported recipient countries including Morocco, loss liability, holding/charge/refund rules and settlement currency. Before custody: approve third-party recipient authorization, evidence and code delivery. Before any feature rollout: implement and test grants/RLS, current-session restrictions, rate limiting and nonce CSP. Production still requires recovery rehearsal, privacy/retention decisions and commercial hosting.
